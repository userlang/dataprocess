# dataprocess

#### Description
本次架构涉及到的技术点：Mysql+Canel+RocketMQ+SpringBoot+ElasticSearch+Redis
项目初衷：由于MySql数据增多，系统查询缓慢 所以优化现有系统，希望可以把一些数据放到ES和Redis等一些缓存中去处理，这里dataprocess主要解决的是监听MQ中的消息并给使用者提供 增，删，改一些过滤器接口，供使用者方便处理数据或写入到ES，Redis中
